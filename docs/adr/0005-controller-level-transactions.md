# Транзакции на уровне контроллеров при отключённом open-in-view

Статус: принято

## Контекст

`spring.jpa.open-in-view=false` (чтобы запросы к БД не прятались в слое представления). Сервисы
возвращают сущности с ленивыми связями, а преобразование в DTO происходит в контроллере после
завершения транзакции сервиса, то есть возникает `LazyInitializationException`.

## Решение

Контроллеры, которые вызывают сервис и маппят результат, помечены `@Transactional`
(`readOnly = true` для `GET`). Внутренние `@Transactional` сервисов присоединяются к внешней.
Наружу отдаются только DTO, сущности в ответах не используются.

## Последствия

- Простое решение без изменения сигнатур сервисов; транзакция живёт чуть дольше обычного.
- Нарушает «чистое» разделение слоёв. Целевое состояние: сервисы приложения возвращают DTO,
  контроллеры без транзакций.
- Нельзя ставить `readOnly = true` на изменяющие методы: запись в такой транзакции не сбросится.
