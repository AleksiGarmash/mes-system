# Бумажный чек-лист остаётся первичным документом (document-first)

Статус: принято

## Контекст

Оператор смесителя работает в перчатках, связь в цеху нестабильна, персонал привык к бумажным
листам, а процесс взвешивания нельзя прерывать ради ввода данных в планшет. При этом нужна
прослеживаемость и контроль отклонений.

## Рассмотренные варианты

1. Ввод в систему в реальном времени при каждом взвешивании.
2. Бумажный чек-лист как первичный документ; система оцифровывает его фото после партии.
3. Полностью электронный чек-лист (замена бумаги).

## Решение

Вариант 2. Лист заполняется вручную, затем фотографируется; система определяет документ по QR,
распознаёт поля, сверяет с рецептурой, показывает оператору только сомнительные строки и после
подтверждения создаёт электронную запись. Оригинал фото хранится как первичный документ.
Режим реального времени (вариант 1) оставлен как альтернативный путь на тех же таблицах.

## Последствия

- Процесс в цеху не меняется, оригинал остаётся для аудита, переход к электронным листам возможен позже.
- Данные появляются с задержкой, поэтому контроль «на месте» невозможен.
- Качество системы определяется качеством распознавания и удобством экрана проверки.
- OCR скрыт за интерфейсом `OcrEngine`; сейчас подключена заглушка.
