# Допуск рецептуры в процентах, допуск качества диапазоном

Статус: принято

## Контекст

У компонентов рецептуры есть целевая масса, допуск относителен и часто несимметричен («только вверх на 1–2%»).
У параметров качества (pH, плотность, влажность) нет целевой величины, есть приемлемый коридор.

## Решение

- Рецептура: `targetQty` плюс раздельные `tolerancePlus` и `toleranceMinus` в процентах (`DosageValidator`).
- Качество: `minValue` и `maxValue` как абсолютные границы, допускается одна граница; для качественных
  параметров список допустимых значений (`RangeValidator`).
- Допуски процесса (контрольные точки рецептуры) и спецификационные допуски хранятся отдельно:
  внутрипроизводственный допуск обычно уже спецификационного.
- В `QualityCheck`, `ProcessControlRecord` и `WeighingRecord` допуск сохраняется как снимок, чтобы паспорт
  старой партии не менялся при выходе новой версии рецептуры или спецификации.

## Последствия

- Версии рецептур и спецификаций неизменяемы: любое изменение — новая версия.
- Для SPC границы берутся из снимка свежей записи.
