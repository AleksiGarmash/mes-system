# Mixing MES — интерфейс

React, TypeScript, Vite, TanStack Query, Keycloak (вход по PKCE).

Главный экран — проверка распознанного чек-листа: слева оригинал бланка, справа строки по стадиям рецептуры. Оператор правит только отмеченные строки; подтверждение недоступно, пока остаются непроверенные строки, и рядом всегда написано почему.

Так же устроен протокол качества для лаборанта: бланк с QR-кодом партии, фото, проверка распознанных значений по спецификации. До подтверждения на экране видно, будет партия выпущена или забракована.

Остальные экраны: задания с печатью бланка, партии и их состав, контрольная карта процесса (SPC), отзыв лота сырья, склад с выдачей по FEFO.

## Запуск

```bash
npm install
npm run dev:demo   # без бэкенда: вымышленные данные в браузере, вход не нужен
npm run dev        # с бэкендом и Keycloak из docker compose
```

Адреса бэкенда и Keycloak задаются в `.env` (пример — `.env.example`).

## Проверки

```bash
npm test           # Vitest и Testing Library
npm run typecheck
npm run build
```
